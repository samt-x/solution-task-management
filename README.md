Oppgavestyring i SAMT-BU: hvordan oppgavene er organisert i GitHub-organisasjonen samt-x.

- **Innhold:** Hugo-modul, montert på docs.samt-bu.no under
  Prosjektleveranser → Løsninger → Samhandlingsplattform → Oppgavestyring.
  Live: https://docs.samt-bu.no/prosjektleveranser/loesninger/samhandlingsplattform/oppgavestyring/
- **Backlog:** Issues i dette repoet gjelder selve oppgavestyringen (oppsett, konvensjoner, brett).
