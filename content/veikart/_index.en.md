The roadmap describes where task management is heading, in three tracks. Each track has steps, and each step is a [milestone in GitHub](https://github.com/samt-x/solution-task-management/milestones). The tracks are described in the subsections.

| Track | Question it answers | Steps |
|---|---|---|
| [Shared setup for the project boards](felles-oppsett/) | How can the boards differ and still be reported together? | M1 Templates and shared status model · M2 Templates in use · M3 Automatic creation of sub-projects |
| [Overview for the individual](oversikt-for-den-enkelte/) | What is assigned to me, across all boards? | A1 Search and view · A2 Aggregate board · A3 Personal board · A4 Other git platforms |
| [Portfolio management](portefoljestyring/) | What is SAMT-BU working on, and how is it going? | B1 Portfolio board · B2 Links to tasks and goals |

The shared setup comes first, because both the aggregate board (A2) and the portfolio board (B1) build on the shared status model.

**Docs owns the direction, GitHub owns the status.** These pages describe the tracks and steps. What has been done and what remains is recorded in the milestones and issues in [solution-task-management](https://github.com/samt-x/solution-task-management/issues), and is updated there.
